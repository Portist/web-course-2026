# Лабораторная работа №1. Семантическая вёрстка. Страница-резюме

Сверстано одностраничное резюме с использованием семантических тегов HTML5 и Flexbox-раскладки.

Проект не использует JavaScript, float или абсолютное позиционирование. Все требования выполнены.

Для просмотра откройте `index.html` через GitHub Pages.
