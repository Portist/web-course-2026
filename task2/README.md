# Лабораторная работа №2. Адаптивная вёрстка лендинга (PUBG: BATTLEGROUNDS)

Сверстан адаптивный учебный лендинг с использованием CSS Grid (для крупной структурной сетки) и Flexbox (для внутренних компонентов). Полностью реализован подход Mobile First (адаптация под мобильный, планшет и десктоп), добавлена стилизованная форма обратной связи и визуальное гамбургер-меню без использования JavaScript.

**Как запустить:**
Откройте файл `index.html` через встроенный сервер вашей IDE  или просто перетащите файл в браузер. При проверке через GitHub Pages проект доступен в папке `task2/`. Рекомендуется проверять адаптивность через DevTools (Ctrl+Shift+M).
